# 📅 December 2026

## ✨ Improvements

- **Quick Picks and Dynamic Dates in Date Fields**  
  Below the calendar of a date field, quick picks set yesterday, today, or the start or end of the week, the month or last month with one click, and show the date each one stands for today. In the filter of a list they set a dynamic date: the field shows an fx icon, its tooltip names the rule and the date it gives today, and a list profile saves the rule, so a profile for last month stays current. **Use fixed date** turns a dynamic date into a fixed one, and **Custom rule** builds other dynamic dates such as "7 days before today". **Alt** + **Down** or **F4** opens the calendar. See [Dates in List Filters](~/doc/ui/lists/filter-dates.md).

## 🐛 Bug Fixes

- **Lists That Load on Open Wait for Preset Filter Values**  
  A list that loads on open sometimes reported its filter as incomplete when a mandatory filter field selects its first entry by itself and that entry arrived late. The list now waits for such fields before it loads, and loads once a slow field has picked its value. A list that is not loaded now says why: it loads only on demand, its filter is incomplete or invalid, or checking the filter took too long. If checking the filter takes too long while the list already shows data, a notification says so; click **Apply Filter** to try again. Back-reference tabs on forms name the same reason in the tooltip of their row count.
