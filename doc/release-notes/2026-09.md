# 📅 September 2026

## ✨ Improvements

- **Shareable List Views**  
  Filters and sorting applied to a list are now stored in the URL. The new **Share List** action copies a reusable link that restores the same list configuration when opened — even when no formatting profile is active. This makes recurring reviews easier to bookmark and filtered views easier to share with colleagues.

- **Badges and Circles in Lists**  
  List columns can now display values as rounded badges or numeric circles. Colours can use semantic values such as success, warning, info, and error, custom hexadecimal colours, or expressions that determine the colour for each row. This makes statuses, priorities, and key figures easier to recognise at a glance.

- **More Helpful Update Notification**  
  The **New version available** notification now includes a link to the release notes, making it easy to discover what has changed before refreshing the application.

- **Clear All Notifications**  
  A new action lets you clear all notifications at once instead of dismissing them individually.

- **Confirm Dialogs with Enter**  
  Message boxes with an **OK** button can now be confirmed by pressing **Enter**, improving keyboard navigation and reducing unnecessary mouse interaction.

- **Markdown in Action Messages**  
  Success messages returned by actions can now contain Markdown. Custom actions can use formatted text, lists, emphasis, and links to present results and follow-up instructions more clearly.

- **Improved Signal Booking**  
  Double-clicking a signal opens a new time entry with the signal's duration pre-filled, making it quicker to turn captured activity into a time booking.

- **ZUGFeRD Invoice PDFs**  
  Invoice report actions support ZUGFeRD 2.3 COMFORT compliant PDF files with embedded structured invoice data. This includes support for seller organisation identifiers, unit codes, invoice notes, and non-EU export tax categories. Availability depends on tenant configuration. This feature will be rolled out gradually.

## 🐛 Bug Fixes

- **Default Formatting Profiles Apply Immediately**  
  When a formatting profile is marked as the default, it is now applied immediately. Reloading the list is no longer necessary.

- **Overtime Calculation for Department Leads**  
  Fixed a permission issue in the `Overtime()` and `Overtime2()` functions. Department leads can now calculate overtime balances correctly for employees in the departments they are permitted to view.

- **Correct Working Hours for Sunday-Based Weeks**  
  Fixed an issue that shifted working hours by one day for locales where the week starts on Sunday, such as English (Australia).

> **Note:**
> These release notes describe what's included in the September 2026 release. Availability can depend on rollout rings and tenant configuration.
