# 📅 April 2026

## ✨ Verbesserungen

- **Konfigurierbarer Dateiname für Berichts-Downloads in Listen**  
  Sie können jetzt einen eigenen Dateinamen für Berichts-Downloads in Listen konfigurieren. Verwenden Sie dazu die Eigenschaft `web:DownloadFilename` im Listen-Tag. Statische Namen und Ausdrücke werden unterstützt – Sie können zum Beispiel Filterparameter und Werte von Entitäten kombinieren, um automatisch aussagekräftige Dateinamen zu erzeugen. Wenn die Eigenschaft fehlt, gilt weiterhin das bisherige Standardverhalten (Listenname + Datum).

- **Verwendetes Profil in der Liste anzeigen**  
  Listen zeigen jetzt den Namen des aktiven Formatprofils statt der allgemeinen Bezeichnung „Profile“. So sehen Sie auf einen Blick, welches Profil auf die aktuelle Listenansicht angewendet ist.

- **Markdown in den Infos zu Formatprofilen**  
  Das Feld `APP_CaptionExpression` in Formatprofilen stellt jetzt Markdown dar. Beschriftungen und Beschreibungen können Überschriften, Fettdruck, Listen und andere Markdown-Elemente verwenden und werden dadurch besser lesbar.

- **Nahtloses Andocken von Zeitbuchungen**  
  Wenn Sie eine neue Zeitbuchung mit der Schaltfläche **+** oder mit **STRG+I** anlegen, beginnt sie jetzt genau am Ende der vorigen Zeitbuchung, ohne auf die nächsten 15 Minuten gerundet zu werden. So erfassen Sie Zeiten leichter lückenlos und ohne Überschneidungen.

- **Verbesserungen bei Signalen**  
  Zwei Verbesserungen der Bedienbarkeit im Bereich **Signale**:
  - Ein Doppelklick auf ein Signal öffnet jetzt eine neue Zeitbuchung, in der die Dauer des Signals bereits eingetragen ist.
  - Die Zeitzusammenfassung der Signale zeigt jetzt die tatsächlich gearbeitete Dauer statt eines Min/Max-Bereichs.

- **Überarbeiteter Dialog beim Löschen eines Benutzers in time cockpit**  
  Der Dialog, der beim Versuch erscheint, einen Benutzer zu löschen, wurde überarbeitet. Er erklärt jetzt, dass ein direktes Löschen nicht unterstützt wird, und leitet Administratoren an, einen Benutzer stattdessen über das Kontrollkästchen **Aktiv** zu deaktivieren.

- **Rechtsklick auf das Gruppenlogo in Listen**  
  Ein Rechtsklick auf ein Gruppenlogo in einer Liste öffnet jetzt das Kontextmenü, genau wie ein Rechtsklick auf die Gruppenzeile selbst.

## 🐛 Fehlerbehebungen

- **URL-Kodierung in Bedingungen**  
  URL-kodierte Zeichen in Listenbedingungen werden jetzt korrekt verarbeitet.

- **Excel-Export: Überschrift mit dem Berichtsnamen erstreckt sich über alle Spalten**  
  Beim Export einer Liste nach Excel über die Druckansicht erstreckt sich die Überschrift mit dem Berichtsnamen jetzt über alle Datenspalten. Bisher wurde sie auf die konfigurierte Seitenbreite abgeschnitten. Die Überschrift ist außerdem linksbündig, wie die anderen Kopfzeilen.

- **Benachrichtigung „Neue Version“ wird seltener angezeigt**  
  Die Benachrichtigung „Neue Version“ erschien zu häufig. Sie wird jetzt seltener angezeigt, um unnötige Unterbrechungen bei der Arbeit zu vermeiden.

- **Schließen von TimesheetAdminForm löscht die Benutzerauswahl**  
  Ein Fehler wurde behoben, der beim Entfernen der Benutzerauswahl in der Beziehungszelle von TimesheetAdminForm auftrat. Die Funktion `HasPermission` behandelt jetzt ein Entitätsobjekt mit dem Wert null korrekt und verhindert so den Fehler.
