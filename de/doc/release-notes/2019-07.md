# Juli 2019

## Web-Client

### OperationId in Zeitbuchungen

Wenn Sie Zeitbuchungen im Kalender oder über das Bearbeitungsformular ändern, wird nach dem Speichern nur die betroffene Zeitbuchung neu geladen. Wenn Trigger Änderungen an weiteren Zeitbuchungen verursachen, werden diese im Kalender erst aktualisiert, wenn der Benutzer alle Zeitbuchungen neu lädt.
