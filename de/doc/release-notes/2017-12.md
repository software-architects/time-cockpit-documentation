# Dezember 2017

## Performance bearbeitbarer Listen

Die Performance bearbeitbarer Listen wurde in der neuen Version verbessert. Verwenden Sie dennoch so wenige Eingabesteuerelemente wie möglich, indem Sie die Zahl der bearbeitbaren Spalten begrenzen und die Zahl der Zeilen mit Filtern einschränken.

## Fehlerbehebungen im HTML5-Client

- Das Verhalten beim Ändern der Größe von Zeitbuchungen im Kalender am Tagesende wurde korrigiert
- In der Dauerauswahl wird der Tag nicht mehr geändert, wenn als Endzeit 00:00 eingegeben wird
- In Listen wird die Skriptquelle verwendet, wenn sie definiert ist, auch wenn TCQL definiert ist
- Leere Abschnitte im Menü werden ausgeblendet
- Die definierte Formularbreite wird verwendet
