# April 2017

## Read-Only-Ausdruck und Berechtigungen im Kalender

Zeitbuchungen, für die Sie keine Schreibberechtigung haben oder die den Read-Only-Ausdruck erfüllen, werden halbtransparent dargestellt. Sie können sie weder in der Größe ändern noch verschieben. Sie können aber weiterhin eine Kopie der betroffenen Zeitbuchungen anlegen. Beim Kopieren einer schreibgeschützten Zeitbuchung werden alle Eigenschaften, die im Read-Only-Ausdruck vorkommen, auf null gesetzt. Nehmen wir an, es gibt den Read-Only-Ausdruck Current.APP_Invoice <> Null. Alle Zeitbuchungen, die einer Rechnung zugeordnet sind, würden halbtransparent dargestellt. Nach dem Kopieren einer solchen Zeitbuchung wird die Eigenschaft für die zugeordnete Rechnung auf null gesetzt.

![Keine Schreibberechtigung im Kalender](/doc/release-notes/images/2017-04/no-write-permission.png "Keine Schreibberechtigung im Kalender")

## Mehrfachauswahl im Grid

Zusätzlich zum Anhaken der Kontrollkästchen in der Spalte ganz links können Sie jetzt mehrere Elemente auswählen, indem Sie beim Klick auf eine Zeile UMSCHALT oder STRG gedrückt halten. UMSCHALT wählt alle Zeilen von der bereits ausgewählten bis zur angeklickten Zeile aus. STRG fügt eine Zeile zu den bereits ausgewählten Zeilen hinzu oder entfernt sie daraus.

![Mehrfachauswahl im Grid](/doc/release-notes/images/2017-04/multi-select.png "Mehrfachauswahl im Grid")

## Optionsfelder für boolesche Werte

Diese Funktion gibt es im Vollclient schon seit einiger Zeit, und diesen Monat hat sie ihren Weg in den neuen HTML5-Client gefunden. Mit der BooleanRadioButtonCell können Sie einen Text für die Werte True, False und Null festlegen.

```html
<Form ModelEntityName="USR_BooleanRadioButtonCellTestEntity" xmlns="http://www.timecockpit.com/2009/ui/data">
  <Tab Header="Project">
    <Section Header="General">
      <SectionColumn>
        <BooleanRadioButtonCell Content="=Current.USR_Billable" FalseText="Not billable" TrueText="Billable" NullText="Unknown" Header="Billable" />
        ...
```

Die angegebenen Texte werden neben den Optionsfeldern angezeigt.

![Boolean Radio Button Cell](/doc/release-notes/images/2017-04/boolean-radio-button-cell.png "Boolean Radio Button Cell")

Sie können die BooleanRadioButtonCell auch in Listen verwenden. Auch dort wird der Text statt eines Kontrollkästchens angezeigt.

## Bessere Größenanpassung von Grids

Fußzeilen mit Aggregaten werden jetzt unterhalb der letzten Inhaltszeile des Grids angezeigt statt am unteren Rand des Browserfensters.

## Fehlerbehebung: Drucken von PDF-Berichten funktionierte nicht

Das Drucken von PDF-Berichten auf einem Rechner mit installiertem .NET Framework 4.6 funktionierte in früheren Versionen nicht. Um das Problem zu beheben, mussten wir auf die neue Version der Telerik Controls aktualisieren.
