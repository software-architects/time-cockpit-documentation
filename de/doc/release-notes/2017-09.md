# September 2017

## Fehlerbehebungen

- Aus Musterbuchungen können jetzt im Kalender Zeitbuchungen angelegt werden, die bis Mitternacht dauern.
- Wenn in Rückverweis-Tabs Änderungen vorgenommen werden, werden Formulare erneut validiert.
- Einige Änderungen in Formularen wurden nicht erkannt und lösten keine Validierung aus.
- Die Genauigkeit numerischer Eigenschaften wurde in New With-Abfragen ignoriert.
