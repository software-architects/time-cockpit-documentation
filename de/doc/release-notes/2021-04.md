# April 2021

## Kalender

In der Oberfläche des neuen Zeiterfassungskalenders gibt es einige Änderungen:

### Einstellungen

Wir haben den Menüpunkt *Plugins* entfernt, stattdessen gibt es in der Symbolleiste über dem Kalender den neuen Eintrag *Einstellungen*.

![Dialog Einstellungen](/doc/release-notes/images/2021-04/settings.png "Dialog Einstellungen")

### Office 365

Wenn Sie im neuen Einstellungsdialog *Office 365 Kalendereinträge anzeigen* oder *Office 365 gesendete E-Mails anzeigen* aktiviert haben, finden Sie in der Symbolleiste über dem Kalender ein neues Symbol. Es wird gelb hervorgehoben, wenn Sie gerade nicht angemeldet sind.

![Office 365](/doc/release-notes/images/2021-04/office365.png "Office 365")

### Mobile Ansicht

In der mobilen Ansicht des Kalenders können Sie Zeitbuchungen jetzt verschieben und in der Größe ändern. Drücken Sie eine Sekunde lang auf eine Zeitbuchung, um Drag & Drop zu aktivieren. Sobald sich die Farbe ändert, können Sie den Eintrag verschieben.

![Mobile Ansicht](/doc/release-notes/images/2021-04/mobile-view.png "Mobile Ansicht")

Wenn Sie auf eine Zeitbuchung tippen, werden Anfasser eingeblendet, mit denen Sie Beginn- und Endzeit ändern können.

![Größenänderung in der mobilen Ansicht](/doc/release-notes/images/2021-04/mobile-resize.png "Größenänderung in der mobilen Ansicht")

Wischen Sie nach links oder rechts, um den ausgewählten Tag zu wechseln.

## Formulare

### SaveButtonCell

Mit einem neuen Formular-Steuerelement können Sie im Formular eine Schaltfläche zum Speichern anzeigen.

```html
<web:SaveButtonCell 
    Content="='Save and load dependencies'" 
    Header=" " 
    Icon="save" 
    LabelPosition="None" 
    Align="Center|Left|Right" 
    Close="False"
    Foreground="=:Iif(Current.APP_Description = 'red', 'Red', 'Green')" 
    IsEnabled="=:Iif(Current.APP_Description = 'test', False, True)"
    IsVisible="=:Iif(Current.APP_Description = 'test', 'Collapsed', 'Visible')" />
```

Die Liste der verfügbaren Symbole finden Sie unter https://www.telerik.com/kendo-angular-ui/components/styling/icons/.

![Schaltfläche Speichern](/doc/release-notes/images/2021-04/save-button.png "Schaltfläche Speichern")
