# August 2017

## Umgang mit ausgeblendeten Benutzern

In den Benutzereinstellungen von time cockpit gibt es ein Kontrollkästchen, mit dem Sie einen Benutzer ausblenden können. Das ist keine neue Funktion, aber ab dieser Version wird die Einstellung „Ausgeblendet“ in nahezu allen Listen und Formularen von time cockpit berücksichtigt (Ausnahmen sind unten aufgeführt). Ausgeblendete Benutzer werden also standardmäßig nicht mehr angezeigt, um die Übersichtlichkeit zu verbessern.

In einigen Listen (etwa **Benutzerdetails**, **Benutzerstatusliste**, **Urlaubsanspruch** usw.) können Sie ausgeblendete Benutzer wieder anzeigen, wenn Sie den entsprechenden Filter aktivieren:

![Ausgeblendete Benutzer anzeigen](/doc/release-notes/images/2017-08/filter-for-hidden-user.png "Ausgeblendete Benutzer anzeigen")

Listen mit historisch auslaufenden Daten sind von dieser Änderung bewusst ausgenommen. Das betrifft folgende Listen:

- Zeitbuchungen
- Nicht verrechnete Zeitbuchungen
- Arbeitszeitverletzungen

Diese Listen werden meist für einen bestimmten, gefilterten Zeitraum verwendet. Zeitbuchungen auf einem Projekt in der Vergangenheit oder Arbeitszeitverletzungen in der Vergangenheit sollen daher auch für ausgeblendete Benutzer angezeigt werden, damit sie nicht versehentlich übersehen werden. Im Allgemeinen gibt es für ausgeblendete Benutzer im aktuellen Zeitraum keine Zeitbuchungen, sodass sie mit der Zeit aus diesen Listen verschwinden.

### Änderungen bei Feldern zur Benutzerauswahl

In der neuen Version von time cockpit werden ausgeblendete Benutzer standardmäßig nicht mehr in Feldern zur Benutzerauswahl aufgelistet. Wenn Sie dennoch einen ausgeblendeten Benutzer auswählen möchten, öffnen Sie die Basistabelle der Benutzerdetails mit einem Klick auf die Lupe in der Auswahlliste:

![Nach ausgeblendeten Benutzern filtern](/doc/release-notes/images/2017-08/select-hidden-user.png "Nach ausgeblendeten Benutzern filtern")

> [!WARNING]
> Mindestens ein Benutzer in Ihrem Konto muss die neueste Version des time cockpit Vollclients installieren, damit Ihr Konto die neue Version des time cockpit Datenmodells erhält.

## Änderungen in der Liste Urlaub

In der neuen Version von time cockpit enthält die Spalte **description** in der Liste Urlaub auch den Beschreibungstext von Urlaubsansprüchen (grün dargestellt), sofern der Urlaubsanspruch selbst eine Beschreibung enthält. Andernfalls wird nur **Urlaubsanspruch** angezeigt. Vor dieser Version enthielt die Spalte für die Beschreibung immer **Urlaubsanspruch**.

![Urlaubsliste](/doc/release-notes/images/2017-08/vacation-list.png "Urlaubsliste")

> [!WARNING]
> Mindestens ein Benutzer in Ihrem Konto muss die neueste Version des time cockpit Vollclients installieren, damit Ihr Konto die neue Version des time cockpit Datenmodells erhält.

## Fehlerbehebungen

- Im Kalender können Sie jetzt Zeitbuchungen anlegen, die bis Mitternacht dauern.
- Fehler bei der Hervorhebung in Kombinationsfeldern bei der Suche nach Daten sind behoben.
- ImageCells funktionieren jetzt auch in Formularen.
- LookupConditions für RelationCells funktionieren jetzt.
