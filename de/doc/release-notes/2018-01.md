# Januar 2018

## Symbolleiste in Listen und im Kalender

Wir haben die blauen Symbolschaltflächen über Listen und über dem Kalender durch eine Symbolleiste ersetzt, die für jede Schaltfläche ein Symbol und eine Beschriftung anzeigt.

![Symbolleiste in einer Liste](/doc/release-notes/images/2018-01/toolbar-in-list.png "Symbolleiste in einer Liste")

Auf kleineren Geräten werden die Beschriftungen der Schaltflächen weggelassen, damit trotzdem alle Schaltflächen in einer Zeile angezeigt werden können.

![Symbolleiste in einer Liste auf einem kleinen Gerät](/doc/release-notes/images/2018-01/toolbar-in-list-phone.png "Symbolleiste in einer Liste auf einem kleinen Gerät")

Wenn der verfügbare Platz tatsächlich für alle Schaltflächen zu klein wäre, erscheint rechts ein Pfeil, mit dem Sie einen Überlaufbereich für die Schaltflächen aufklappen können, die im Hauptbereich der Symbolleiste keinen Platz haben.

## Neue Kendo-Steuerelemente

Wir haben auf die neueste Version der [Kendo UI](https://demos.telerik.com/kendo-ui/)-Steuerelemente aktualisiert und auf deren Default Theme umgestellt. Daher sehen viele Steuerelemente wie Textfelder, Datumsauswahlen, Kombinationsfelder oder Schaltflächen in der neuen Version etwas anders aus.

![Kendo-Steuerelemente](/doc/release-notes/images/2018-01/kendo-controls.png "Kendo-Steuerelemente")

## Fehlerbehebungen im HTML5-Client

- Ausgewählte Zeilen in Listen gehen beim Scrollen nicht mehr verloren
- Änderungen in bearbeitbaren Listen werden beim Zuklappen der übergeordneten Gruppe nicht mehr verworfen
- Im Kalender können Sie jetzt per Touch scrollen und Elemente auswählen
