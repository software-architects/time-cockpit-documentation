# Februar 2018

## Reporting Services

Wir haben die Microsoft Reporting Services-Komponenten zum Erzeugen von PDF-, Excel- und Word-Dokumenten auf die neueste Version aktualisiert.

## Fehlerbehebungen

- Einige ActionCells konnten nicht auf das aktuelle EntityObject zugreifen
- Das Monatsformat in der Datumsauswahl verwendet jetzt den abgekürzten Monat
