# Oktober 2017

## Verbesserungen beim Import

- Der Fortschritt von Importen wird angezeigt
- Leere Schlüssel werden beim Import nicht verarbeitet
- Importe können abgebrochen werden
- Typen der Quellspalten können für Formeln angegeben werden
- Blobs werden beim Import nicht geladen
- Vorverarbeitungsausdrücke werden jetzt gecacht
