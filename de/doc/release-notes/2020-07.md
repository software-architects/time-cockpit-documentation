# Juli 2020

## Fehlerbehebungen & Verbesserungen

- Mehrere Zeitbuchungen innerhalb eines Tages können ausgewählt werden. Die Anzahl der ausgewählten Zeitbuchungen und die Summe ihrer Dauer werden rechts unten angezeigt.
- Wenn Sie eine Zeitbuchung auswählen, werden die Signaldetails auf der rechten Seite auf den ausgewählten Zeitraum eingeschränkt.
- Gruppenüberschriften in gruppierten Listen werden auch bei Umlauten korrekt sortiert.
- Gruppenüberschriften in gruppierten Listen zeigen bei booleschen Werten "yes" und "no" an.
- Der Gruppierungsstatus von Listen wird beim Export der Liste berücksichtigt.
- Die Label-Position None funktioniert jetzt.
