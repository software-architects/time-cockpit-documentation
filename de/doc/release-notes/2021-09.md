# September 2021

## Fehlerbehebungen & Verbesserungen

- fix: AutoRefreshOnDataUpdates funktioniert in HTML5 nicht
- fix: Beim Ausführen einer Aktion wird kein ValidationException-Text angezeigt
- fix: ExecuteWithoutPrompt von Aktionen wird in HTML5 ignoriert
- fix: Die Größenänderung im Kalender funktioniert nicht, wenn eine Zeitbuchung um 00:00 endet
