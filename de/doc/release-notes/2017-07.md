# Juli 2017

## Performance

### Caching der Werte von Kombinationsfeldern

In der neuen Version werden die Werte von Kombinationsfeldern im Local Storage des Browsers zwischengespeichert. time cockpit führt pro Modellentität die letzte Update-Version. Der Web-Client ruft die letzten Update-Versionen regelmäßig ab und bereinigt den Cache, wenn sich die letzte Update-Version einer Modellentität geändert hat. Der folgende Screenshot zeigt alle Webservice-Anfragen, die nötig sind, um das Formular zum Bearbeiten einer Zeitbuchung zum ersten Mal zu öffnen:

![Performance ohne Caching](/doc/release-notes/images/2017-07/open-timesheetentry-form.png "Performance ohne Caching")

Beim nächsten Öffnen desselben Formulars sind deutlich weniger Anfragen an den Server nötig:

![Performance mit Caching](/doc/release-notes/images/2017-07/open-timesheetentry-form-with-caching.png "Performance mit Caching")

Folgende Aktionen leeren den Cache eines Kombinationsfelds:

- **Klick auf „Daten im Cache löschen“ im Menü**: Damit werden alle zwischengespeicherten Werte von Kombinationsfeldern entfernt.

- **Entitätsobjekt im selben Browser bearbeiten**: Jeder Cache-Eintrag weiß, von welchen Modellentitäten er abhängt. Das Kombinationsfeld für Projekte hängt zum Beispiel von `APP_Project` und von `APP_Customer` ab, das im Anzeigenamen verwendet wird (z. B. Demo Customer.First Project). Sobald Sie im selben Browser ein Projekt oder einen Kunden bearbeiten, werden alle zwischengespeicherten Werte von Kombinationsfeldern, die Projekte anzeigen, sofort entfernt.

- **Entitätsobjekt in einem anderen Browser oder im Vollclient bearbeiten**: Der Web-Client prüft jede Minute die letzte Update-Version aller Modellentitäten. Wurde ein Entitätsobjekt geändert, werden die zwischengespeicherten Werte spätestens nach einer Minute entfernt.

- **Keine Aktion**: Der Cache wird nach 24 Stunden bereinigt, und die Werte werden neu vom Server geladen, wenn ein Kombinationsfeld sie das nächste Mal anfordert.

### Caching statischer Dateien

Wir haben das Caching statischer Dateien wie CSS-, JavaScript- oder JSON-Ressourcen verbessert. Einige davon wurden in früheren Versionen nicht korrekt zwischengespeichert. Das verkürzt die anfängliche Ladezeit von time cockpit.

## Fehlerbehebungen

- Texte, die in Zeitbuchungen im Kalender angezeigt werden, dürfen jetzt `<` und `>` enthalten.
- FileCells müssen keine Liste erlaubter Dateiendungen mehr enthalten.
- Im Zeiterfassungskalender muss ein Benutzer ausgewählt sein, bevor eine neue Zeitbuchung angelegt werden kann.
