# Dezember 2019

## Fehlerbehebungen & Verbesserungen

- Tastaturereignisse (z. B. TAB) funktionierten in Comboboxen nicht
- Der Cache von Comboboxen wurde nicht automatisch neu geladen, wenn sich Daten geändert haben
- Formulare werden jetzt mit CSS Grid dargestellt.
- Das Signal-Tracker-Plugin ist standardmäßig deaktiviert.
- Das Layout der Abwesenheitsbeschreibungen im Zeiterfassungskalender wurde korrigiert.
- Beim Speichern-Button in Listen mit Mehrfachbearbeitung werden keine Bestätigungsmeldungen mehr angezeigt.
