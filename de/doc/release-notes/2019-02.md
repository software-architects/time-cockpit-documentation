# Februar 2019

## Fehlerbehebungen & Verbesserungen

* Wenn Abfragen für Musterbuchungen im Zeiterfassungskalender einen Fehler verursachten, konnten keine neuen Zeitbuchungen angelegt werden. Jetzt wird der Fehler unterhalb des Bereichs der Musterbuchungen angezeigt, und Sie können weiterhin neue Zeitbuchungen anlegen.
* Urlaub, Krankenstand und Zeitausgleich werden im Kalender über die Anzeigenamen (Friendly Names) der Modellentitäten übersetzt.
* Wenn Sie Zeitbuchungen per Doppelklick auf eine Musterbuchung anlegen, wird die Beginnzeit automatisch auf die Endzeit der letzten Zeitbuchung des ausgewählten Tages gesetzt.
* Filterbedingungen konnten nicht an Listen mit Skriptquellen übergeben werden.
* Die Aggregation von Zellen in gruppierten Listen funktionierte bei bearbeitbaren Feldern nicht
