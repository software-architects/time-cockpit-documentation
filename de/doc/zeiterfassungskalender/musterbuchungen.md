# Musterbuchungen

Musterbuchungen sind eine leistungsfähige Funktion von time cockpit, die Ihre Zeiterfassung vereinfacht und effizienter und einheitlicher macht. Musterbuchungen sind vorkonfigurierte Zeitbuchungen, die Sie schnell in Ihre Zeiterfassung übernehmen können. Mit Musterbuchungen müssen Sie dieselben Informationen nicht immer wieder manuell eingeben. Wählen Sie einfach die passende Musterbuchung aus und übernehmen Sie sie in Ihre Zeiterfassung.

### Musterbuchung anlegen

Mit Musterbuchungen in time cockpit erfassen Sie wiederkehrende Aufgaben und Tätigkeiten einfacher. Sie können Musterbuchungen für häufige Aufgaben anlegen und sie bequem in Ihre Zeiterfassung übernehmen. So legen Sie Musterbuchungen an und verwenden sie:

1. **Zeitbuchung anlegen**: Legen Sie zuerst eine neue Zeitbuchung für die Aufgabe oder Tätigkeit an, aus der Sie eine Musterbuchung machen möchten. Füllen Sie alle relevanten Informationen wie Beschreibung, Dauer und weitere Details aus und klicken Sie dann auf **Speichern**.

2. **Als Muster speichern**: Klicken Sie mit der rechten Maustaste auf die angelegte Zeitbuchung und wählen Sie **Als Muster speichern**.

3. **Musterbuchung benennen**: Geben Sie einen Namen für die Musterbuchung ein und speichern Sie sie.

4. **Musterbuchung aufrufen**: Die neue Musterbuchung steht im Bereich **Musterbuchungen** links in time cockpit zur Verfügung.

### Musterbuchung bearbeiten

Musterbuchungen sind sehr flexibel und lassen sich anpassen, wenn sich Ihre Projekte und Aufgaben weiterentwickeln. Sie können Beschreibung, Dauer und alle anderen Details einer Musterbuchung einfach ändern. So bearbeiten Sie eine Musterbuchung:

1. **Musterbuchung aufrufen**: Klicken Sie links in time cockpit mit der rechten Maustaste auf die Musterbuchung, die Sie ändern möchten, und wählen Sie **Musterbuchung bearbeiten**.

2. **Änderungen vornehmen**: Ein Formular für Zeitbuchungen wird geöffnet, in dem Sie die Details der Musterbuchung nach Bedarf ändern können.

3. **Musterbuchung speichern**: Wenn Sie Ihre Änderungen abgeschlossen haben, klicken Sie auf **Template speichern**.

>[!NOTE]
> Wenn das Formular Validierungsfehler enthält und die Kriterien einer gültigen Zeitbuchung nicht erfüllt (zum Beispiel, weil Pflichtangaben fehlen), können Sie die Musterbuchung trotzdem speichern. time cockpit fordert Sie dann beim Verwenden der Musterbuchung auf, die fehlenden Pflichtfelder auszufüllen. Haben Sie dagegen eine gültige Musterbuchung angelegt, speichert time cockpit die Zeitbuchung direkt, ohne einen Dialog zu öffnen.

## Drag & Drop
Musterbuchungen lassen sich einfach per Drag & Drop übernehmen. Ziehen Sie eine Musterbuchung in den Zeiterfassungskalender oder legen Sie sie auf einem Signalbalken oder einem Outlook-Termin ab.

**Am Signalbalken ausrichten:**
Wenn Sie eine Musterbuchung auf einen Signalbalken ziehen, übernimmt sie automatisch die Dauer des Signalbalkens. So legen Sie Zeitbuchungen auf Basis vordefinierter Musterbuchungen einfacher an, und sie passen genau zu Ihren Signalen.

**Am Outlook-Termin ausrichten:**
Wenn Sie eine Musterbuchung auf einen Outlook-Termin ziehen, bestimmen Sie genau, was dabei herauskommt:

  - Legen Sie die Musterbuchung auf der **linken Seite** des Outlook-Termins ab, bleiben Beschreibung und Dauer aus der Musterbuchung erhalten.
  - Legen Sie die Musterbuchung auf der **rechten Seite** des Termins ab, übernimmt sie Beschreibung, Ort und Dauer des darunterliegenden Outlook-Termins.
