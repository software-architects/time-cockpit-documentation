# Überstunden/Urlaub auszahlen

## So zahlen Sie Überstunden aus
Um Überstunden auszuzahlen, legen Sie eine neue Überstundenkorrektur an. Beim Anlegen einer neuen Überstundenkorrektur füllen Sie folgende Felder aus:

| Feld           | Beschreibung                                                        |
| -------------- | ------------------------------------------------------------------- |
| Benutzer       | der Mitarbeiter, dem Überstunden ausgezahlt werden                  |
| Effective Date | das gewünschte Datum (Tagesbeginn) der Überstundenkorrektur         |
| Overtime       | gewünschte Anzahl an Überstunden zum Stichtag                       |

#### Beispiel
Tim Smith hat Ende April 2017 44 Überstunden und möchte zu diesem Zeitpunkt 24 Stunden ausgezahlt bekommen. Dazu legen Sie eine Überstundenkorrektur mit dem Stichtag 1.5.2017 und einem Überstundenwert von 20 Stunden (44-24) an.


## So zahlen Sie Urlaub aus
Um Urlaub auszuzahlen, legen Sie einen negativen Urlaubsanspruch an. Beim Anlegen eines neuen Urlaubsanspruchs füllen Sie folgende Felder aus:

| Feld                | Beschreibung                                                         |
| ------------------- | -------------------------------------------------------------------- |
| Benutzer            | der Mitarbeiter, dem Urlaub ausgezahlt wird                          |
| Date of Entitlement | das gewünschte Datum des Urlaubsanspruchs                            |
| Number of Weeks     | gewünschte Anzahl an Wochen, die ausgezahlt werden                   |

#### Beispiel
Tim Smith hat Ende Juni 2017 2 Wochen Urlaub und möchte diese 2 Wochen ausgezahlt bekommen, weil sein Dienstverhältnis mit Juni 2017 endet. In diesem Fall legen Sie einen Urlaubsanspruch mit 'Number of Weeks' -2 und 'Date of Entitlement' 30.6.2017 an.
