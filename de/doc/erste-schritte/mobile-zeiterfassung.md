# Leitfaden für mobile und responsive Zeiterfassung

Verwenden Sie time cockpit auf jedem mobilen Gerät über Ihren Webbrowser. Der responsive Web-Client passt sich an Smartphones und Tablets an und ermöglicht so die Zeiterfassung unterwegs.

> [!TIP]
> **Sie suchen eine mobile Zeiterfassung?** Der Web-Client von time cockpit bietet einen responsiven, mobilfreundlichen Zugriff, ohne dass Sie eine native App benötigen. Erfahren Sie mehr über [moderne Funktionen für die Zeiterfassung](https://www.timecockpit.com/features/time-tracking-calendar/).

## Überblick

time cockpit hat keine eigene native mobile App. Stattdessen bietet es eine **responsive Webanwendung**, die in mobilen Browsern reibungslos funktioniert:

**Die wichtigsten Vorteile:**
- ✅ **Keine App-Installation nötig** - Funktioniert in jedem modernen mobilen Browser
- ✅ **Dieselbe vertraute Oberfläche** - Einheitliches Erlebnis auf Desktop und Mobilgerät
- ✅ **Immer aktuell** - Keine App-Updates zum Herunterladen
- ✅ **Plattformübergreifend** - Funktioniert unter iOS, Android und auf Tablets
- ✅ **PWA-Unterstützung** - Installation als Progressive Web App für ein App-ähnliches Erlebnis

**Zugriff von überall:**
- URL: **https://web.timecockpit.com**
- Funktioniert auf iPhone, iPad, Android-Smartphones und Android-Tablets
- Erfordert eine Internetverbindung (cloudbasiert, kein Offlinemodus)

## Erste Schritte auf dem Mobilgerät

### time cockpit auf Ihrem Gerät öffnen

**iPhone/iPad:**
1. Öffnen Sie den Browser **Safari** oder **Chrome**.
2. Navigieren Sie zu: **https://web.timecockpit.com**
3. Melden Sie sich mit Ihren Zugangsdaten an (dieselben wie am Desktop).
4. Die Oberfläche passt sich automatisch an die Bildschirmgröße an.

**Android-Smartphone/-Tablet:**
1. Öffnen Sie den Browser **Chrome** oder **Firefox**.
2. Navigieren Sie zu: **https://web.timecockpit.com**
3. Melden Sie sich mit Ihren Zugangsdaten an.
4. Touch-freundliche Bedienelemente werden automatisch aktiviert.

### Zum Startbildschirm hinzufügen (empfohlen)

Legen Sie ein App-ähnliches Symbol für den schnellen Zugriff an:

**Auf iPhone/iPad:**
1. Öffnen Sie **https://web.timecockpit.com** in Safari.
2. Tippen Sie auf die Schaltfläche **Teilen** (Quadrat mit nach oben zeigendem Pfeil).
3. Wählen Sie **Zum Home-Bildschirm**.
4. Geben Sie als Namen "Time Cockpit" ein.
5. Tippen Sie auf **Hinzufügen**.
6. Das Symbol erscheint wie bei einer nativen App auf dem Home-Bildschirm.

**Auf Android:**
1. Öffnen Sie **https://web.timecockpit.com** in Chrome.
2. Tippen Sie auf das **Menü** (drei Punkte).
3. Wählen Sie **Zum Startbildschirm hinzufügen**.
4. Geben Sie als Namen "Time Cockpit" ein.
5. Tippen Sie auf **Hinzufügen**.
6. Das Symbol erscheint auf dem Startbildschirm.

**Vorteile:**
- Start von time cockpit mit einem Tippen
- Fühlt sich an wie eine native App
- Keine Browserleiste (Adressleiste) beim Start
- Schnellerer Zugriff als Browser öffnen und URL eintippen

## Installation als Progressive Web App (PWA)

Installieren Sie time cockpit als Progressive Web App für ein besseres Erlebnis:

### Installation am Desktop

**Google Chrome:**
1. Öffnen Sie **https://web.timecockpit.com** in Chrome.
2. Suchen Sie in der Adressleiste (rechts) nach dem Symbol **Time Cockpit installieren**.
3. Klicken Sie darauf, um die App zu installieren.
4. time cockpit öffnet sich als eigenständiges Fenster (ohne Browser-Tabs).

**Microsoft Edge:**
1. Öffnen Sie **https://web.timecockpit.com** in Edge.
2. Suchen Sie in der Adressleiste nach dem Symbol **App verfügbar. Time Cockpit installieren**.
3. Klicken Sie darauf, um die App zu installieren.
4. Die App startet als eigenständige Anwendung.

### Vorteile der PWA

- **Eigenständiges Fenster**: Keine störenden Browser-Bedienelemente
- **Symbol in Taskleiste/Dock**: Einfacheres Wechseln mit Alt+Tab
- **Desktop-Benachrichtigungen**: Hinweise auch dann, wenn die App nicht aktiv ist
- **Schnellerer Start**: Öffnet direkt, ohne den ganzen Browser zu starten
- **Tableisten**: Aktivieren Sie "Desktop PWA tab strips" unter [chrome://flags/](chrome://flags/) oder [edge://flags/](edge://flags/), um die PWA mit mehreren Tabs zu nutzen

## Was auf dem Mobilgerät gut funktioniert

### ✅ Schnelle Zeiterfassung

**Zeitbuchungen anlegen:**
- Tippen Sie auf **+** oder **Neu**.
- Wählen Sie Projekt/Tätigkeit aus den Auswahllisten (für Touch optimiert).
- Legen Sie Beginn- und Endzeit mit den mobilen Zeitauswahlen fest.
- Geben Sie eine kurze Beschreibung ein.
- Tippen Sie auf **Speichern**.

**Ideal für:**
- Erfassung direkt nach dem Ende einer Besprechung
- Erfassung von Reisezeiten unterwegs
- Schnelle Einträge zwischen zwei Aufgaben

### ✅ Tagesansicht im Kalender

**Ihren Tagesablauf ansehen:**
1. Navigieren Sie zu **Zeiterfassung** → **Zeiterfassungskalender**.
2. Wechseln Sie in die **Tagesansicht** (am besten für kleine Bildschirme).
3. Scrollen Sie durch die Einträge.
4. Sehen Sie Urlaubs- und Abwesenheitsblöcke.
5. Tippen Sie auf Einträge, um Details anzuzeigen.

**Vorteile der Tagesansicht auf dem Mobilgerät:**
- Weniger horizontales Scrollen
- Größere Tippflächen
- Auf kleinen Bildschirmen besser lesbar

### ✅ Urlaubsanträge

**Abwesenheit beantragen:**
1. Navigieren Sie zu **Benutzer** → **Urlaub**.
2. Tippen Sie auf **Neu**.
3. Wählen Sie die Art der Abwesenheit (Urlaub, Krankenstand usw.).
4. Wählen Sie Beginn- und Enddatum (mobile Datumsauswahl).
5. Geben Sie einen Grund oder Notizen ein.
6. Reichen Sie den Antrag zur Genehmigung ein.

**Mobilfreundlicher Ablauf:**
- Urlaub auch auf Reisen beantragen
- Urlaubsstand von überall prüfen
- Benachrichtigungen über Genehmigungen auf dem Smartphone erhalten

### ✅ Erfasste Zeiten prüfen

**Ihre Stunden überprüfen:**
- Sehen Sie aktuelle Einträge in der Listenansicht an.
- Filtern Sie nach Zeitraum.
- Prüfen Sie die erfasste Zeit.
- Prüfen Sie die Summen für Woche/Monat.

**Anwendungsfälle:**
- Tägliches Stand-up: Stunden vom Vortag nachsehen
- Wöchentliche Durchsicht: Vollständigkeit der Zeitbuchungen bestätigen
- Schnelle Kontrolle, bevor Sie Ihre Zeiten abgeben

### ✅ Timer starten/stoppen

**Live-Timer (falls verfügbar):**
- Timer mit einem Tippen starten
- Im Lauf des Tages zwischen Aufgaben wechseln
- Timer stoppen und Eintrag speichern
- Verstrichene Zeit auf einen Blick sehen

## Einschränkungen auf Mobilgeräten und Lösungsansätze

### ❌ Wenig Platz auf dem Bildschirm

**Herausforderung:**
- Komplexe Berichte wirken gedrängt.
- Listen mit vielen Spalten erfordern horizontales Scrollen.
- Detaillierte Formulare sind unter Umständen schwer zu bedienen.

**Empfehlung:**
- Verwenden Sie den Desktop für:
  - das Erstellen von Berichten
  - das Bearbeiten vieler Zeitbuchungen auf einmal
  - komplexe Projekteinrichtung
  - Budgetanalysen

**Lösungsansatz:**
- Nutzen Sie auf dem Tablet das Querformat für mehr Bildschirmfläche.
- Verwenden Sie vereinfachte Ansichten, wenn verfügbar.
- Exportieren Sie Berichte per E-Mail und sehen Sie sie später am Desktop an.

### ❌ Lange Beschreibungen tippen

**Herausforderung:**
- Auf Smartphone-Tastaturen tippen Sie langsamer als am Desktop.
- Ausführliche Beschreibungen sind auf kleinen Bildschirmen mühsam.

**Lösungsansatz:**
1. **Eintrag auf dem Mobilgerät anlegen** mit den wichtigsten Angaben:
   - Projekt/Tätigkeit
   - Dauer
   - Kurze Notiz
2. **Vollständige Beschreibung später am Schreibtisch ergänzen**:
   - Eintrag am Desktop öffnen
   - Ausführliche Notizen, Links usw. ergänzen

**Bewährte Vorgehensweise:**
- Mobil: "Kundentelefonat - Onboarding"
- Desktop (später): "Telefonat mit Acme Corp zum Onboarding für das neue Projekt, Anforderungserhebung für Phase 1, Fragen zur technischen Architektur, nächste Schritte für 15. Februar geplant"

### ❌ Keine Signalaufzeichnung

**Herausforderung:**
- Die Aktivitätsaufzeichnung (Signal Tracker) erfordert den Vollclient am Desktop.
- Nicht aufgezeichnet werden können:
  - aktive Fenster
  - Dateiänderungen
  - Computeraktivität
  - Netzwerkverbindungen

**Lösungsansatz:**
- Verwenden Sie den Desktop-Client für die automatische Aktivitätsaufzeichnung.
- Sehen Sie aufgezeichnete Signale im mobilen Web-Client an (nur lesend).
- Erfassen Sie mobile Arbeit (Telefonate, Reisen, Besprechungen) manuell.

Siehe: [Signal Tracker - Überblick](/doc/signal-tracker/overview.html) (nur Desktop)

### ❌ Keine Anpassung des Datenmodells

**Herausforderung:**
- Die Struktur des Datenmodells lässt sich auf dem Mobilgerät nicht ändern.
- Entitäten bearbeiten, eigene Felder und Berechtigungen müssen am Desktop erledigt werden.

**Auf dem Mobilgerät verfügbar:**
- Angepasste Felder verwenden (am Desktop angelegt)
- Alle eigenen Entitäten und Listen funktionieren wie gewohnt
- Berechtigungen werden durchgesetzt

Siehe: [Anpassung des Datenmodells](/doc/data-model-customization/overview.html)

### ❌ Internetverbindung erforderlich

**Herausforderung:**
- Kein Offlinemodus
- Eine Internetverbindung (WLAN oder mobile Daten) ist erforderlich.
- Ohne Verbindung können Sie keine Zeiten erfassen.

**Empfehlung:**
- Verwenden Sie mobile Daten, wenn kein WLAN verfügbar ist.
- Notieren Sie Zeiten auf Papier, wenn Sie komplett offline sind, und erfassen Sie sie später.
- Kurze Verbindungsunterbrechungen werden problemlos abgefangen (automatische Wiederverbindung).

## Mobile Abläufe und bewährte Vorgehensweisen

### 1. Kundentermine vor Ort

**Szenario:** Verrechenbare Stunden beim Kunden erfassen

**Ablauf:**
1. **Vor dem Termin**: time cockpit auf dem Smartphone öffnen
2. **Timer starten** (oder Beginnzeit notieren)
3. **Während des Termins**: Kurze Notizen in der Notizen-App machen
4. **Nach dem Termin**: Zeitbuchung auf dem Smartphone anlegen:
   - Kundenprojekt auswählen
   - Dauer eingeben
   - Kurze Beschreibung: "Kundentermin - Anforderungen"
5. **Zurück im Büro**: Ausführliche Notizen zum Eintrag ergänzen

### 2. Außendienst / Reisezeit

**Szenario:** Zeit erfassen, während Sie zwischen Standorten unterwegs sind

**Ablauf:**
1. **Ankunft vor Ort**: Eintrag für die Reise anlegen:
   - Tätigkeit: "Reise" oder "Fahrt"
   - Dauer: Fahrzeit
   - Ort: "Büro → Kundenstandort A"
2. **Geleistete Arbeit**: Eintrag für die Arbeit vor Ort anlegen
3. **Abfahrt**: Eintrag für die Rückreise anlegen
4. **Am Ende des Tages**: Einträge am Desktop durchsehen und auf Richtigkeit prüfen

### 3. Remote-Arbeit / verteilte Teams

**Szenario:** Teammitglieder arbeiten an verschiedenen Orten

**Ablauf:**
1. **Morgens**: Kalender auf dem Arbeitsweg am Smartphone prüfen
2. **Im Lauf des Tages**: Einträge am Laptop/Desktop anlegen (bevorzugt)
3. **Abends**: Kurzer mobiler Check, ob der Tag vollständig ist
4. **Gedanke am Wochenende**: "Habe ich die Besprechung vom Freitag erfasst?" → Am Smartphone prüfen und bei Bedarf ergänzen

### 4. Schnellerfassung

**Szenario:** Arbeitsreicher Tag mit vielen Aufgabenwechseln

**Ablauf:**
1. **Während der Arbeit**: Tätigkeiten in der Notizen-App festhalten:
   ```
   9-10: Client A call
   10-11:30: Code review
   11:30-12: Email
   12-1: Lunch
   1-3: Development - Feature X
   ```
2. **Am Ende des Tages**: time cockpit am Smartphone oder Desktop öffnen
3. **Sammelerfassung**: Zeitbuchungen aus den Notizen anlegen
4. **Vorteil**: Tagsüber festhalten, später erfassen (mobil oder am Desktop)

## Besonderheiten auf Tablets

### Tablet oder Smartphone

**Tablets (iPad, Android-Tablet) bieten ein besseres Erlebnis:**
- ✓ Größerer Bildschirm = weniger Gedränge
- ✓ Wochenansicht besser nutzbar
- ✓ Listen zeigen mehr Spalten
- ✓ Berichte sind leichter lesbar
- ✓ Tippen ist einfacher (größere Bildschirmtastatur oder physische Tastatur)

**Empfehlung:**
- Smartphone: Schnelle Einträge, Kalender prüfen, Urlaubsanträge
- Tablet: Nahezu Desktop-Erlebnis, gut für Remote-Arbeit
- Desktop: Voller Funktionsumfang, komplexe Aufgaben, Berichte, Anpassung

### Unterstützung für Tastatur und Maus

**iPadOS-/Android-Tablets mit Tastatur:**
- Bluetooth-Tastatur funktioniert
- Maus/Trackpad wird unterstützt
- Desktop-ähnliches Erlebnis möglich
- Tastenkombinationen funktionieren eventuell (abhängig vom Browser)

## Tipps für erfolgreiche mobile Zeiterfassung

### 1. Eingaben vereinfachen

**Auf dem Mobilgerät bevorzugen:**
- ✓ Auswahllisten für Projekt/Tätigkeit (touch-freundlich)
- ✓ Vordefinierte Werte
- ✓ Zeitauswahl (statt manueller Eingabe)
- ✓ Kurze Beschreibungen
- ✓ Standardtätigkeiten

**Auf dem Mobilgerät vermeiden:**
- ✗ Lange Freitextbeschreibungen
- ✗ Komplexe Nachschlagefelder über mehrere Beziehungen
- ✗ Massenoperationen
- ✗ Erweiterte Filter

### 2. Eine Routine etablieren

**Tägliche mobile Gewohnheiten:**
- **Morgens**: Kalenderansicht für heute prüfen (2 Min.)
- **Im Lauf des Tages**: Einträge direkt nach den Tätigkeiten anlegen (je 1 Min.)
- **Abends**: Einträge des Tages kurz durchsehen (3 Min.)
- **Wöchentlich**: Am Desktop auf Vollständigkeit und Details prüfen (15 Min.)

### 3. Lesezeichen und Verknüpfungen verwenden

**Schneller navigieren:**
- Legen Sie im mobilen Browser ein Lesezeichen für **https://web.timecockpit.com** an.
- Fügen Sie time cockpit für App-ähnlichen Zugriff zum Startbildschirm hinzu.
- Richten Sie zur Sicherheit eine Anmeldung mit PIN oder Biometrie ein.
- Der Browser merkt sich die Zugangsdaten (falls gewünscht).

### 4. Mobil und Desktop kombinieren

**Optimaler Ablauf:**
- **Stärke von mobil**: Zeit sofort und unterwegs erfassen
- **Stärke des Desktops**: Ausführliche Beschreibungen, Berichte, Administration
- **Zusammen**: Die genauesten Zeitbuchungen mit dem geringsten Aufwand

**Beispiel:**
- Montag bis Freitag: Schnelle mobile Einträge im Lauf des Tages (2-3 Min./Tag)
- Freitagnachmittag: Durchsicht am Desktop, Details ergänzen, Berichte ausführen (20 Min.)

### 5. Benachrichtigungen nutzen

**Bei der Erfassung am Ball bleiben:**
- Aktivieren Sie Browserbenachrichtigungen auf dem Smartphone.
- Erhalten Sie Erinnerungen an unvollständige Zeitbuchungen (falls konfiguriert).
- Benachrichtigungen über Genehmigungen von Urlaubsanträgen
- Budgetwarnungen für Projektleiter

## Leistung auf Mobilgeräten

### Anforderungen an die Verbindung

**Mindestens:**
- 3G-Mobilfunk: Nutzbar, aber langsamer
- 4G/LTE: Gute Leistung
- 5G: Ausgezeichnete Leistung
- WLAN: Optimal

**Datenverbrauch:**
- Gering: Zeitbuchungen, Kalender ansehen
- Eintrag anlegen: typischerweise < 100 KB
- Berichte erstellen: Kann mehr Daten verbrauchen (bei begrenztem Datenvolumen vermeiden)

### Browserkompatibilität

**Empfohlene mobile Browser:**

**iOS:**
- ✅ Safari (beste Integration in iOS)
- ✅ Chrome (einheitlich über Plattformen hinweg)

**Android:**
- ✅ Chrome (empfohlen)
- ✅ Firefox (gute Alternative)
- ⚠️ Samsung Internet (funktioniert meist, gelegentliche Darstellungsfehler)

**Verwenden Sie für beste Leistung und Sicherheit immer die neueste Browserversion.**

## Probleme auf Mobilgeräten beheben

### Probleme bei der Anmeldung

**Problem:** Anmeldung auf dem Mobilgerät nicht möglich

**Lösungen:**
1. Prüfen Sie die URL: **https://web.timecockpit.com** (nicht http, nicht .org)
2. Prüfen Sie die Zugangsdaten (dieselben wie am Desktop).
3. Versuchen Sie einen anderen Browser.
4. Löschen Sie Browser-Cache und Cookies.
5. Prüfen Sie die Internetverbindung.

### Darstellungsprobleme

**Problem:** Die Oberfläche wirkt fehlerhaft oder gedrängt

**Lösungen:**
1. Drehen Sie das Gerät ins Querformat.
2. Zoomen Sie mit den Browser-Bedienelementen heraus (Zwei-Finger-Geste).
3. Wechseln Sie im Kalender in die Tagesansicht.
4. Aktualisieren Sie den Browser auf die neueste Version.
5. Versuchen Sie einen anderen Browser.

### Leistungsprobleme

**Problem:** Langsames Laden oder Verzögerungen

**Lösungen:**
1. Prüfen Sie die Stärke der Internetverbindung.
2. Schließen Sie andere Browser-Tabs.
3. Starten Sie die Browser-App neu.
4. Löschen Sie den Browser-Cache.
5. Wechseln Sie von mobilen Daten zu WLAN (oder umgekehrt).

### Zeitbuchung wird nicht gespeichert

**Problem:** Ein Eintrag lässt sich nicht speichern oder scheint gespeichert, verschwindet aber wieder

**Lösungen:**
1. Prüfen Sie die Internetverbindung (Sie müssen online sein).
2. Prüfen Sie, ob alle Pflichtfelder ausgefüllt sind.
3. Prüfen Sie, ob Validierungsfehler angezeigt werden (roter Text).
4. Aktualisieren Sie die Seite (nicht gespeicherte Änderungen können verloren gehen).
5. Machen Sie einen Screenshot der Fehlermeldung und wenden Sie sich an den Support.
