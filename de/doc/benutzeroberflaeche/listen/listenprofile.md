# Profile

## Überblick

Mit der Funktion Profile von time cockpit passen Benutzer die Anzeigeeinstellungen von Listen in time cockpit an ihre Arbeitsweise an. Benutzer können Profile anlegen, verwalten und auf Listen anwenden, einschließlich Einstellungen wie angezeigte Spalten, Spaltenreihenfolge, Gruppierung, Auf- und Zuklappstatus der Gruppierung und Sortierreihenfolge. Profile werden pro Benutzer in der Datenbank gespeichert und sind dadurch auf jedem Gerät und in jedem Browser verfügbar.

## Wichtige Funktionen

### Die Schaltfläche "Profile"

Die Profilfunktion ergänzt jede Liste in time cockpit um eine zusätzliche Schaltfläche mit der Beschriftung "Profile".

- Benutzer können Listeneinstellungen anpassen, einschließlich angezeigter Spalten, Spaltenreihenfolge, Gruppierung, Auf- und Zuklappstatus der Gruppierung und Sortierreihenfolge.
- Profile können benannt werden, damit sie leicht zu erkennen und zu verwalten sind.

### Profilaktionen

- **Ansicht zurücksetzen:** Setzt die Ansicht einer Liste auf die Standardeinstellungen zurück.
- **Profil speichern:** Bestehende Profile können aktualisiert werden, um geänderte Listeneinstellungen zu übernehmen.
- **Als neues Profil speichern:** Benutzer können ein neues Profil mit angepassten Listeneinstellungen anlegen.
- **Profil löschen:** Benutzer können Profile löschen, die sie nicht mehr benötigen.

### Ein Profil als Standard festlegen

- Benutzer können ein Profil als Standardansicht für eine Liste festlegen.
- Ist ein Profil als Standard festgelegt, öffnet sich die Liste mit den Einstellungen dieses Profils.
- Ist kein Standardprofil ausgewählt, öffnet sich die Liste in der von time cockpit bereitgestellten Standardansicht, und Benutzer können manuell ein Profil auswählen.

## Anwendungsfälle

### Wann ist diese Funktion nützlich?

Die Profilfunktion ist besonders in folgenden Szenarien nützlich:

1. **Listenansichten anpassen:** Benutzer können Listenansichten auf ihre Bedürfnisse zuschneiden und nur die Informationen anzeigen, die für sie am wichtigsten sind.

2. **Effizientes Arbeiten:** Mit Profilen wechseln Benutzer je nach Aufgabe schnell zwischen verschiedenen Ansichten und arbeiten dadurch effizienter.

3. **Einheitlich auf allen Geräten:** Da Profile in der Datenbank gespeichert werden, können Benutzer auf jedem Gerät und in jedem Browser auf ihre angepassten Listeneinstellungen zugreifen und haben überall dieselbe Arbeitsumgebung.
